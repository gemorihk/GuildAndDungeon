## ✨ 遊戲特色 (Game Features)

* **自由跨職業轉職系統**：角色從「0階無業遊民」起步，達到指定六維屬性門檻後可自由轉職，且學會的技能永遠保留！
* **雙等級成長機制**：角色等級（自由配點） + 職業等級（解鎖獨特技能）。
* **地下城討伐與 Boss 戰**：6 大元素屬性關卡，累積 10 波討伐解鎖強大層級 Boss！
* **裝備與藥水系統**：7 大裝備部位、商店藥水儲備與自動喝藥設置。
* **本地自動存檔**：支援手機與電腦瀏覽器，進度自動即時儲存於 LocalStorage。
